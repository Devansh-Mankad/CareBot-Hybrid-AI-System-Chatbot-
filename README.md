# CareBot AI

CareBot is an AI-powered rural healthcare assistant built using Streamlit, Machine Learning, and Gemini AI.

## Features

* Symptom analysis
* AI-powered healthcare guidance
* Multilingual support
* Voice input support
* Disease prediction using ML model
* Home remedies and prevention tips

## Tech Stack

* Streamlit
* Python
* Scikit-learn
* Gemini AI
* Hugging Face Spaces

This application is for educational purposes only and is not a substitute for professional medical advice.
